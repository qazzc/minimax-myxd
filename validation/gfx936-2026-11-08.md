## Quality Correction

Initial 124-frame files and SSIM values of 96.741%/96.787% were misleading: visual review found colorful mosaic corruption in both InfiniLM and PyTorch `--legacy` output. Those values establish matching dimensions/frame count only and are not valid quality evidence. A H3 fused-projection order correction uses `auto [up, gate]` followed by `swiglu(up, gate)`; the earlier reversed order and repeated-forward workaround were removed.

## Successful gfx936 Runs

After the H3 MLP correction, the formal InfiniLM entry completed a gfx936 8-card run with seed 42, 50 configured steps, 124 frames, 576x384, 24 FPS, and prompt `A dog falls asleep`. The run decoded 124 frames and was visually inspected. It predates the later RNG/stream stability fixes and must not be treated as the final candidate result.

Three later candidate runs after the VAE posterior-generator and asynchronous handoff fixes are summarized in `github-clone-2026-11-09.md`: 124 frames each, with 87.448%, 89.580%, and 89.746% SSIM versus a fixed-seed local PyTorch reference. The organizer reference and acceptance threshold remain unchecked.

## NineToothed Operator

The gfx936 Hygon-BW1000 AOT path uses the scoped `--hygon-ninetoothed-swiglu=y` option. The official InfiniCore SwiGLU test passed for F16/BF16/F32, representative 2D/3D shapes, strided tensors, and out-of-place/in-place modes. A fresh isolated rebuild and repeat of this operator test on 2026-11-10 also passed.

## Historical Build and Batch Evidence

An isolated clean package rebuild completed for InfiniCore and InfiniLM. A sequential two-case 50-step smoke batch returned exit code 0 for both cases, with 124 decoded frames, 576x384, 24 FPS, and audio. Historical SSIM values of 96.741%/96.787% belong to mosaic-corrupted outputs and are invalid as quality evidence. The second case used a demonstration prompt, not an organizer hidden case.

## Limits

- This validates gfx936 only. It does not establish NineToothed AOT or end-to-end inference support on gfx906 or gfx938.
- The 2026-11-10 rebuild passed, but a new full inference from that fresh prefix was deferred because shared jobs occupied approximately 52-53 GiB per 64 GiB device.
- No official organizer-reference threshold or multi-case preliminary gate has been confirmed; do not claim the competition is passed.
- Raw logs and generated MP4s are omitted from the repository. Recreate them by running the documented commands and use the competition-provided model and data.
