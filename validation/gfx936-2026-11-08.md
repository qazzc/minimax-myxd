## FL2VA 正式路径

运行入口是 `InfiniLM/examples/minimax_h3.py fl2va`，没有 `--legacy`。模型权重、首帧、提示词和工作量均未更换或缩减：

```bash
export LD_LIBRARY_PATH=/tmp/infini-gfx936-ninetoothed-test/lib:$LD_LIBRARY_PATH
export MINIMAX_H3_TORCH_SDPA_BACKEND=math
cd /code/Projects/InfiniLM
/workspace/envs/minimax-h3/bin/python examples/minimax_h3.py fl2va \
  --model-path /code/models/MiniMax-H3/diffusers \
  --text "A dog falls asleep" \
  --gpus 0,1,2,3,4,5,6,7 \
  --steps 50 --seed 42 --height 384 --width 576 \
  --first-frame /code/data/Golde33443.jpg --num-frames 124 \
  --output /code/outputs/fl2va-gfx936-ninetoothed-50step-124f-mathsdpa.mp4
```

日志通过 `[verify] FL2VA frames: 124/124 PASS`，模型执行 49 次 scheduler iteration（配置为 50 steps），H3 Transformer 计算耗时 150.247 秒，端到端耗时 245.189 秒。打包日志见 `logs/gfx936-infinilm-fl2va-50step.log`。

PyAV 解码检查结果：H.264，576×384，24 FPS，124 帧，AAC 音轨；视频帧 RGB 均值范围为 68.15 至 95.74，非黑帧。正式路径样例已打包为 `media/fl2va-gfx936-infinilm-50step-124f.mp4`。

`MINIMAX_H3_TORCH_SDPA_BACKEND=math` 仅用于这次验证中 Diffusers VAE 的 PyTorch SDPA。正式 H3 Transformer 仍走 InfiniLM/InfiniCore 路径。复现环境应保持同一 DTK 镜像；若 VAE 的 fused SDPA 在目标镜像可用，可不设置此兼容变量。

## 参考对比

为与纯 PyTorch `--legacy` 路径比较，在 gfx936 容器中将 `torch.nn.functional.scaled_dot_product_attention` 换成按 query 维度 1024 分块的普通 PyTorch dense attention，以避免原生 fused SDPA 插件不匹配和完整 attention 矩阵的显存峰值。完整 QKᵀ、softmax 和 AV 计算均保留；该 fallback 不进入正式推理路径。可复现启动器为 `scripts/run_legacy_math_reference.py`。

参考输出和 InfiniLM 输出使用同一个官方比较程序：

```bash
cd /code/Projects/InfiniLM
/workspace/envs/minimax-h3/bin/python examples/minimax_h3_compare.py \
  --model-path /code/models/MiniMax-H3/diffusers \
  --tasks fl2va \
  --reference-fl2va-video /code/outputs/fl2va-gfx936-reference-legacy-50step-124f-torch-chunked-1024.mp4 \
  --infinilm-fl2va-video /code/outputs/fl2va-gfx936-ninetoothed-50step-124f-mathsdpa.mp4 \
  --output-dir /code/outputs/gfx936-ninetoothed-124f-compare
```

历史结果：尺寸 PASS（双方 576×384），长度 PASS（双方 124 帧），Average SSIM `96.787%`。**该相似度现判定为无效质量证据**：视觉检查确认双方均为马赛克。比较日志见 `logs/gfx936-fl2va-comparison.log`，两路运行日志分别见 `logs/gfx936-legacy-reference-50step.log` 和 `logs/gfx936-infinilm-fl2va-50step.log`。PyTorch 参照路径使用了分块 PyTorch attention，其运行时间不用于正式性能排名。
